rclone

rclone is a command-line application that lets you sync, copy and back up files between your computer and your own Google Drive.

How it works Privacy Policy Terms of Service

What is rclone?

rclone is the name of this application: a Google OAuth client that connects the open-source rclone command-line program to the Google Drive API. It is maintained and operated by an independent developer (GitHub: kaczmarekb-eng).

The application runs entirely on the user's own computer. It has no web interface, no user accounts and no servers of its own – this website is purely informational and is available to everyone without signing in.

This application is not affiliated with, endorsed by, or sponsored by Google LLC or by the authors of the open-source rclone project. "Google Drive" is a trademark of Google LLC.

Purpose of the application

The purpose of rclone is to let a user manage their own files stored in Google Drive from the command line. With rclone the user can:

Back up

Copy local folders to Google Drive to keep a safe off-site backup.

Sync

Keep a local directory and a Google Drive folder identical, in either direction.

Download & restore

Download files and folders from Google Drive back to the computer.

List & check

List files, check sizes and compare checksums to verify that backups are complete.

rclone only performs the operations that the user explicitly starts with a command (for example rclone copy, rclone sync or rclone ls). It never runs in the background on its own and never accesses Google Drive on behalf of anyone else.

How it works

  1. The user installs rclone on their computer and runs rclone config to add a Google Drive remote.
  2. rclone opens Google's sign-in page in the browser. The user signs in with their Google account and reviews the permissions requested on Google's consent screen.
  3. After the user grants consent, Google returns an OAuth access token and refresh token. They are saved only on the user's computer, in the local rclone configuration file.
  4. When the user runs a command, rclone talks directly to the Google Drive API over HTTPS. File contents and metadata travel only between the user's computer and Google – they are never sent to the developer or to any third party.

How rclone uses Google user data

rclone requests access to Google Drive only so that it can carry out the file operations the user asks for (listing, uploading, downloading, moving and deleting the user's own files). Google user data is:

  • used only to provide the file-transfer features described above;
  • not collected, stored or viewed by the developer – there is no backend server;
  • not sold, shared with third parties, or used for advertising;
  • not used to train artificial intelligence or machine-learning models.
rclone's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Full details are in the Privacy Policy.

Revoking access

You can revoke rclone's access to your Google account at any time on the Google Account – Third-party apps & services page. To also remove the locally stored tokens, delete the remote with rclone config delete <remote-name> or delete the rclone configuration file.
